# Windows 远程安装移除与默认密码提示规则设计

**状态：** 已获需求确认，待规格审阅

**日期：** 2026-09-19

## 1. 目标

本次只调整 Windows 被控端：

1. 完整移除之前新增的 Windows 远程静默安装软件功能。
2. 当 Windows 被控端当前生效的永久密码仍为默认密码 `Ooo000#@!` 时，已授权的远程桌面连接不自动拉起连接管理器窗口；永久密码被修改后，保持现有“有人远程”提示行为。

Android、macOS、Linux 的运行行为不在本次范围内。

## 2. 现状与关键边界

### 2.1 远程安装功能

该能力不是单一 UI 入口，而是由以下链路组成：

- Rust 远程安装协议、清单校验、权限和会话处理。
- Windows 下载、MSI/EXE 执行、缓存和自愈服务。
- Flutter 远程工具栏入口、安装表单、状态模型和 FFI。
- `hbb_common` 的消息协议、权限枚举和远程安装策略。
- Rust/Flutter 测试和 CI 专用测试步骤。

移除时采用按功能边界的定向删除，不对当前分支做大范围 `git revert`，避免覆盖工作区中已经存在的设备分组、版本显示、Android 启动和其他无关改动。历史设计文档保留为开发记录，不参与构建和运行时引用。

### 2.2 Windows“有人远程”窗口

当前 Windows 连接流程由 Rust 侧产生 `Client` 连接事件，Flutter `ServerModel.addConnection` 接收事件后调用 `showCmWindow()`。因此提示窗口的控制点是连接事件中的“是否显示连接管理器”属性，而不是修改远程认证协议或关闭连接。

未授权的连接请求必须继续显示连接管理器，以便用户执行接受/拒绝操作；只有已经授权的远程桌面连接在默认密码条件下抑制窗口。

## 3. 设计

### 3.1 完整移除远程静默安装

删除远程安装专属的 Rust 模块、Windows 安装/自愈模块、Flutter 弹窗与状态模型、FFI 导出、工具栏入口、权限/能力广告、协议消息、策略配置、测试和 CI 引用。

`hbb_common` 子模块的调整必须保留与本需求无关的现有行为，特别是当前 Windows/Android 默认永久密码逻辑；只移除远程软件安装的协议字段、权限枚举和策略配置。工作区已有的脚本、APK 工作流等无关未提交文件不修改。

普通远程桌面、文件传输、终端、摄像头、权限同步和现有 Windows 服务功能继续沿用原路径。

### 3.2 默认密码下抑制 Windows 连接管理器窗口

在 `hbb_common` 配置层增加一个无副作用的“当前生效永久密码是否匹配指定明文”判断，支持：

- 本地永久密码优先于预置密码。
- 当前哈希存储、旧版明文存储和预置密码存储格式。
- 不返回或记录密码明文，仅在内存中比较候选值与存储值对应的哈希。

在 Rust 连接管理器内部的 `Client` 状态增加 `show_cm_window` 字段。创建连接状态时按以下规则计算：

| 连接状态 | Windows 被控端密码为默认值 | `show_cm_window` |
| --- | ---: | ---: |
| 已授权远程桌面 | 是 | `false` |
| 已授权远程桌面 | 否 | `true` |
| 未授权远程桌面 | 任意 | `true` |
| 文件传输、终端、摄像头、端口转发 | 任意 | 保持现有行为 |

Flutter `Client.fromJson` 对缺失字段按 `true` 兼容；连接新增和已有连接恢复时，仅当仍有连接要求显示窗口时调用 `showCmWindow()`。这不会断开会话，也不会隐藏已经由用户打开的窗口；只控制新连接是否自动唤起提示窗口。

### 3.3 不改变的行为

- 非 Windows 平台不采用默认密码抑制规则。
- 默认密码下未授权请求仍显示连接管理器，不能因为“默认密码”跳过用户确认。
- 非默认永久密码继续沿用现有提示和接受/拒绝流程。
- 远程端的连接建立、认证、权限和数据通道不因窗口抑制而改变。

## 4. 测试策略

按照测试先行执行：

1. 先为密码存储匹配、窗口显示决策和 JSON 兼容行为添加测试，并确认新测试在实现前失败。
2. 实现最小配置 helper、连接状态字段和 Flutter 显示条件。
3. 删除远程安装专属代码后运行 Rust 编译/单元测试和 Flutter 测试/分析，确认没有残留运行时引用。

至少覆盖以下回归场景：

- 默认永久密码 + 已授权远程桌面：不自动显示窗口。
- 自定义永久密码 + 已授权远程桌面：仍自动显示窗口。
- 默认永久密码 + 未授权远程桌面：仍显示窗口。
- 非远程连接类型：保持原窗口规则。
- 本地密码、预置密码、哈希存储和旧版存储格式判断正确。
- 远程安装相关协议、权限、入口、Windows worker 和 CI 测试引用均已移除；普通远程控制链路仍可编译。

## 5. 验收标准

- Windows 构建中不存在可调用的远程静默安装入口、FFI、协议处理、策略开关或自愈安装 worker。
- Windows 被控端默认永久密码下，授权远程桌面连接不会自动弹出连接管理器窗口。
- 修改永久密码后，授权远程桌面连接恢复原有“有人远程”提示。
- 未授权连接仍能通过连接管理器接受或拒绝。
- Android 端行为没有被本次改动改变。
- 工作区中与本需求无关的已有修改保持不变。

## 6. 预期修改面

远程安装移除主要涉及：`src/remote_software.rs`、`src/platform/windows_remote_software.rs`、`src/server/connection.rs`、`src/client.rs`、`src/client/io_loop.rs`、`src/flutter.rs`、`src/flutter_ffi.rs`、`src/ui_session_interface.rs`、`src/lib.rs`、`src/platform/mod.rs`、Flutter 远程工具栏/模型/测试、`hbb_common` 协议与配置，以及相关 CI 文件。

默认密码窗口规则主要涉及：`hbb_common` 密码配置 helper、`src/ui_cm_interface.rs`、`flutter/lib/models/server_model.dart` 及其测试；不会改动 Android 的连接弹窗逻辑。
